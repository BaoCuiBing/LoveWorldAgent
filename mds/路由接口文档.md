# 路由接口文档

`src-tauri/src/rouer/` 与 `src-tauri/src/api.rs` 全部 HTTP 接口速查。服务 `127.0.0.1:8866`（`HTTP_HOST`/`HTTP_PORT` 可覆盖）；生产窗口同源直连该地址，开发态由 Vite 代理 `/api` 到 8866。

## 通用约定

- 除 `/api/health` 与 SSE 流外，响应统一 `{code,msg,data}`，`code=200` 成功（`state::ok/fail`）。
- 错误码：参数非法 400、不存在 404、冲突/审批无待决 409、终端超限 429、写盘失败 500、禁写 403。
- 规则/技能/智能体异常文案含「不存在」映射 404，其余 400。
- 落盘：chat/theme/layout → `config.json`；models/agent → `.loveword/agent_config.json`；permission → `agent_permission.json`；browser/settings → `agent_browser.json`；computer-use → `agent_computer_use.json`；office → `agent_office.json`；mobile → `agent_mobile.json`；会话/用量/上下文 → `data/lwa.db`（旧库首次启动自动备份为 `lwa.db.bak` 后重建）；MCP → `agent_mcp.json`。
- 配置写入均为临时文件 + `rename`（`config::atomic_write_json`），并保留同文件其它字段。

## 对话（chat_sse_router.rs，前缀 `/api/chat`）

| 方法 | 路径 | 入参 | 返回 |
| --- | --- | --- | --- |
| GET | `/sse` | — | `{ask,todo,notify{banner,sound,volume}}` |
| PUT | `/sse` | 同上结构 | 规整后的 chat 段 |
| GET | `/sse/sound/<win\|wait\|error>` | — | `audio/mpeg`；名称非法/缺文件 404 |
| POST | `/stream` | `{message,session_id?,model?,agent?,history?,context_tokens?,context_limit?,attachments?}` 或 `{resume:session_id}` | SSE（`data:` 后为单行 goose `AgentEvent` JSON；会话运行/压缩中返回 409） |
| POST | `/stop` | `{run_id}`（即会话 id） | `{run_id,stopped:true}`；触发该会话 `CancellationToken` 中断本轮；`run_id` 为空 400、会话不存在 404 |
| POST | `/compress` | `{session_id,history?,model?,agent?,context_tokens?}` | SSE（`text/event-stream`）：依次输出思考过程、开始提示、`CompactionCard`（含 `operations.context.compacted`）并落库、压缩完成提示与压缩基线；空历史 400、无会话 404、与对话或压缩并发 409 |
| POST | `/approve` | `{run_id,decision:once\|always\|reject\|answer,answers?}` | `{run_id,decision,resumed}`；`run_id` 即会话 id；无待决 409、会话不存在 404 |

SSE 帧（`data:` 后为单行 JSON，直接是 goose `AgentEvent`，无 `[DONE]`；状态机 Done/Failed 关闭流，等待审批时提前关闭）：

| type | 字段 | 含义 |
| --- | --- | --- |
| `message` | `{message}` | goose `Message`：`{id,role,created,content[],metadata}`；`content[].type` ∈ `text`/`thinking`/`toolRequest`/`toolResponse`/`actionRequired`/`error` 等 |
| `usage` | `{usage}` | ProviderUsage，实际值在 `usage.usage`：`input_tokens/output_tokens/cache_read_input_tokens/cache_write_input_tokens/total_tokens` |
| `messageUsage` | `{messageId,usage}` | 单条消息用量：`usage.{inputTokens,outputTokens,cacheReadTokens,cacheWriteTokens,totalTokens}` |
| `mcpNotification` | `{server,notification}` | MCP 服务通知，前端暂不渲染 |
| `historyReplaced` | `{messages}` | 整体替换对话（goose `Message` 数组），用于上下文压缩等场景 |

- `message` 同 id 分片合并：`text`/`thinking` 追加，`toolRequest`/`toolResponse` 按 `id` 覆盖，`actionRequired` 按 `data.id` 覆盖。
- 审批：`content[]` 中 `actionRequired` 且 `data.actionType="toolConfirmation"` 时携带 `{id,toolName,arguments,prompt}`；`POST /approve` 写一条不可见 `toolConfirmationResponse` 消息，再 `POST /stream {resume:会话id}` 续流。
- `decision`：`once`/`always` → `AllowOnce`（`always` 同时记入权限 `custom`），`reject` → `Cancel`，`answer` 仅用于 `ask_user`，答案回填 `answers`。
- 首轮由后端创建/校验会话并写入 `user` 消息；旧的 `assistant/init`、`part/upsert`、`assistant/paused` 等帧已废弃。

| --- | --- | --- | --- |
| POST | `/upload` | multipart `file` | `{name,origin,size,path}`；≤20MB |
| GET | `/upload/preview` | `?name=` | 图片二进制；非图片 400、不存在 404 |
| DELETE | `/upload` | `?path=` 或 `{path}` | `{name}`；仅 `UPLOAD_DIR` 内 |

## MCP（mcp_config_router.rs，前缀 `/api/mcp`）

| 方法 | 路径 | 入参 | 返回 data |
| --- | --- | --- | --- |
| GET | `` | — | `{total,list,types}`；`env/headers` 的值脱敏为 `****`，编辑时提交 `****` 会保留原值；`/json` 仍返回真实值 |
| GET | `/status` | `?name=` | 单项或全部真实连接探测 |
| POST | `` | `{name,type,command?,args?,env?,url?,headers?,enabled?}` | `{total,list}`；重名/校验失败 400 |
| PUT | `/<name>` | 同上（可改名） | `{total,list}` |
| DELETE | `/<name>` | — | `{total,list}` |
| PATCH | `/<name>/enabled` | `{enabled}` | `{total,list}` |
| GET | `/json` | — | `{text}`：`{servers:[...]}` JSON 文本 |
| PUT | `/json` | `{text}` | 校验后落盘 |

- 配置 `.loveword/agent_mcp.json`；SSE 会话内用 `agent/mcp.rs` 的 `McpRuntime` 连接启用项，工具名加 `mcp_<server>__` 前缀，经 `permission.tool_needs_approval("mcp", tool)` 门禁。

## 窗口、清库与帮助文档（other_router.rs）

| 方法 | 路径 | 入参 | 返回 data |
| --- | --- | --- | --- |
| POST | `/api/win/update` | `{theme,repaint?}` | `{ok,theme,dark,hwnd,repaint}` |
| POST | `/api/open` | `{name}` | `{path}`；仅 `.loveword/doc_mds`，穿越 400、不存在 404 |
| GET | `/api/data/clear` | — | `{sessions,messages,running}`（预览计数与运行态，含 `active_tasks` 锁校验） |
| POST | `/api/data/clear` | — | 单事务清空 7 张会话相关表（`messages/turns/session_usage/session_context/session_compaction/context_facts/sessions`），返回计数；任务运行或压缩中返回 409 |
| POST | `/api/app/quit` | — | `{closed:true}`；后台限时 1.5s 清理终端、MCP 与 sidecar |
| POST | `/api/app/exit` | — | `{exiting:true}`；关闭主窗口并退出进程 |

- `/api/win/update` 为 Tauri 实现：`theme` 取 `dark/light/system`（非法 400）→ `window.set_theme()`；`repaint` 取 `setting/nca/text/policy/invalidate/hide/minrestore`（不提供 `recreate`），`text` 会短暂改写标题触发重绘；`hwnd` 为窗口句柄。原生菜单跟随系统主题，仅记录日志（不再逐项刷色）。
- `/api/open` 用 `explorer.exe` 拉起 `.loveword/doc_mds` 内文档。
