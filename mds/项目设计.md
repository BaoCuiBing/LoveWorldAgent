## 当前基线（2026-11-24）

- 桌面壳为 Tauri v2 + Rust：`src-tauri/`（`main.rs`/`lib.rs`/`app.rs`/`config.rs`/`state.rs`/`api.rs`），原 Python `backend/` 目录 1:1 映射为 `src-tauri/src/{agent,rouer,utils}`，`agent/store_sqls`、`agent/tools_details`、`agent/model_support` 子模块清晰分层。
- 智能体核心已切换 goose GDK：`goose-agent` / `goose-provider-types` / `goose-providers` / `goose-context-management` 均锁定 `=0.1.0-alpha.13`，`goose-providers` 启用 `native-tls`（Windows Schannel）；`agent/model_support/huawei_maas.rs` 专为华为云 MaaS V2（`openpangu` / `glm-5.x` / `deepseek-v4.1`）归一化推理字段与上下文上限。
- 对话由 goose 状态机驱动，步骤顺序：`Approval → PromptParts(assistant) → ToolOperation → UnhandledToolCalls → MaxTurns → InferenceRunner → ExitOnError`；内建 rule/skill/file/command/terminal/browser/computer/word/ppt/excel/mobile/todo/ask 工具进程内适配 `ToolProvider`，外部 MCP 走 MCP 客户端；`AppState::active_tasks` + `SessionTaskGuard` RAII 锁保障 `/api/chat/stream` 与 `/api/chat/compress` 互斥（409 拦截并发）。
- 会话落 SQLite `src-tauri/static/data/lwa.db`：`sessions`、`messages`（`data` 列存 goose `Message` JSON）、`turns`、`session_usage`、`session_context`、`context_facts`；旧结构库首次启动自动备份为 `lwa.db.bak` 后重建；消息撤回/重发走 `DELETE /api/sessions/<id>/messages/<turn_key>?after=1` 原子删除关联消息与孤儿用量并重算会话状态。
- SSE `/api/chat/stream` 与 `POST /api/chat/compress`（SSE 流式压缩）直接输出 goose `AgentEvent`：`message`、`usage`、`messageUsage`、`mcpNotification`、`historyReplaced`；前端按 `Message.content[]` 渲染 text/thinking/toolRequest/toolResponse/actionRequired/CompactionCard，并提供 `InitState.vue` 启动健康轮询过渡遮罩避免首屏白屏。
- 审批：assistant `Message` 内 `actionRequired`（`actionType=toolConfirmation`，含 id/toolName/arguments/prompt）→ `POST /api/chat/approve {run_id,decision,answers?}` 写确认消息 → `POST /api/chat/stream {resume:run_id}` 续流；权限仍读 `src-tauri/static/.loveword/agent_permission.json`。
- HTTP 由 axum 0.8 + tokio 提供，监听 `127.0.0.1:8866`，同源托管 `webdist` 并回退 `index.html`；SQLite 用 rusqlite（`data/lwa.db`），终端用 portable-pty，浏览器/电脑/Office/移动端 sidecar 走共享 `sidecar_pipe.rs` 命名管道（`PeekNamedPipe` 非死锁读帧 + UTF-8/GBK 防乱码解码）。
- 前端 Vue 3 + Tailwind v4 + shadcn-vue（`components/shadcn_ui`，reka-ui 底座，图标 lucide-vue-next），构建输出 `../webdist`；Element Plus 与 Python 运行时已删除，复杂逻辑拆分至 `utils/{chatContract,chatEventReducer,chatHelpers,codeLang,inputHelpers}.js`。
- 新增 Tauri 原生能力接口：`/api/app/pick_folder`（目录对话框并写 `app.project_path`）、`/api/app/notify`、`/api/app/runtime_info`、`/api/app/log`；退出前提供 `/api/app/quit`（1.5s 后台清理）与 `/api/app/exit`。
- `/api/win/update` 改为 Tauri 主题实现：`window.set_theme` + 标题栏重绘策略，原生菜单跟随系统主题。
- 九页设置弹窗：规则 / 技能 / 对话 / 模型 / 系统 / 权限 / 智能体 / 内置工具 / MCP；「内置工具」为浏览器/电脑/Word/PPT/Excel/移动端六标签（默认浏览器），均支持独立 `auto_screenshot` 开关（Office 三族独立持久化且移除 `allowDirs`）；右栏待办 `AgencyList.vue` 联动选中模型上下文显示实时 token 占用进度条与 SSE 手动压缩。
- 权限 8 组：`mcp`（按服务聚合）、`powershell`（19 条高风险，默认灰）、`browser`（21 个浏览器工具，默认蓝）、`computer`（23 个 `computer_*`）、`word`（12 个 `word_*`）、`ppt`（10 个 `ppt_*`）、`excel`（10 个 `excel_*`）、`mobile`（28 个 `mobile_*`）；待决审批随消息落库、无 TTL；`auto` 下未列命令默认放行，输出重定向强制审批。
- 内置浏览器：Qt6 外壳 + CEF 111.2.7 独立顶层窗口，命名管道 v2；`browser_click/hover/type` 回传元素坐标，`CursorOverlay` 绘制箭头与点击涟漪；WebView2 与浏览器运行缓存统一归入 `static/additional/{webview,cache,browser_cache}`。
- 停止为前后端真实中断：前端 `AbortController` + `POST /api/chat/stop {run_id}` → `AppState::stop(session_id)` 取消 `CancellationToken`；停止前先 reject 待决审批，回合置 `cancelled`、会话置 `interrupted`。
- 卡片职责单一化：`command_run/terminal_*`→CommandCall、`file_write`→DiffChangesCard、`file_delete/file_read/file_list`→FileEdit（不渲染正文）、`mcp_*`→McpCall、`rule_*`→RuleCall（只读）、`skill_*`→SkillCall、`todo_write`→UpdateList、直接 `browser_*`/`computer_*`/`word_*`/`ppt_*`/`excel_*`/`mobile_*`→BuildToolCall（统一样式内置工具单卡）、`agent_call` 子智能体→SubAgents、手动压缩→CompactionCard、未知→UnsupportedCard（其右侧黄色「继续」按钮右对齐）；md_show 只面向新契约。
- 提问全量必答：无「跳过此题」「选填」，后端 `ask_user` schema 仅 `question/options/mode/customNote`；规则工具仅保留 `rule_list`/`rule_read`（`/api/relus` 增删改保留）。
- 桌面自动化：`ai_computer_use`（`computer_use`）独立 crate（内置工具，非外置 MCP），23 个 `computer_*` 工具同名映射主应用；主应用 `utils/computer_use.rs` 托管命名管道 `loveworld_computer_use`，支持 `auto_screenshot`（落 `static/data/computer_screen` 并剥离防入大模型，仅 `/api/computer-use/screenshot` 供右栏面板展示），首次调用拉起、退出整树结束、打包态从 `static/computer_use` 播种；`permission` 的 computer 组 23 项默认允许；`computer-control` 技能默认开启并随开关同步。
- Office 自动化：`ai_office_option`（`office_option`）独立 Rust crate（COM IDispatch 晚绑定），32 个 `word_*/ppt_*/excel_*` 工具共用命名管道 `loveworld_office_option` 与 `.loveword/agent_office.json`（Word/PPT/Excel 各独立 STA 线程互不阻塞，支持可见窗口自动截图落 `static/data/office_screen`、允许全部本地合法路径仅拒绝 UNC/设备路径与 `..` 穿越）；主应用 `utils/office_option.rs` 托管三族开关与截图剥离、打包态从 `static/office_option` 播种；`GET/PUT /api/word-option|ppt-option|excel-option` 与 `/api/office-option/*` 路由；`permission` 的 word/ppt/excel 三组默认允许；`word/ppt/excel-control` 技能与 `word/ppt/exceluse-agent` 随族开关同步。
- 日志体系统一：Rust 主应用 `static/logs/app.log`；sidecar 分别写 `browser_panel.log`、`computer_use.log`、`office_option.log`、`mobile_use.log`，共用 `logging.dir`/`logging.max_lines`（≥100）与 `old_N_` 归档，`LOG_DIR`/`LOG_LEVEL` 环境变量优先；`computer_use`/`office_option`/`mobile_use` 协议帧仅走命名管道。
- 终端标签标题统一「终端」（cwd 单独展示），localStorage 只存 `activeIndex` 与 `tabs[{cwd}]`。
- 右栏联动：点击 `DiffChangesCard` 文件夹图标 → 打开右栏、切「文件」页签、逐级展开父目录并滚动选中、编辑器聚焦；内置工具面板 `SidecarPanelBase.vue` 统一展示步骤与截图。
- 智能体 tools 为 `rule/skill/file/command/browser/computer/word/ppt/excel/mobile`，随包 `browser-agent`、`computeruse-agent`、`worduse-agent`、`pptuse-agent`、`exceluse-agent`、`mobileuse-agent` 骨架。
- 会话状态含 `running/completed/interrupted/failed`；右栏默认宽 `(innerWidth-24)×44%`（420~1000）；文件树默认占右栏 23%。
- 移动端：`ai_mobile`（`mobile_use`）独立 Rust crate + adb，28 个 `mobile_*`；主应用 `utils/mobile.rs` 托管命名管道 `loveworld_mobile`，`GET/PUT /api/mobile-option` 落 `.loveword/agent_mobile.json`；`mobile` 权限组 28 项默认允许，`mobile-control` 技能与 `mobileuse-agent` 随开关同步。
- 启动：`cd frontend && npm install && npm run build`；`cd src-tauri && cargo run`（生产）或 `cargo run -- --dev`（配合 `npm run dev`）。
- 代码分析用 `project-init-analyze`，产物 `test/temp/项目分析快照.md` 与 `test/temp/project_inventory.json`；运行验收用 `project-test`。技能目录为 `.trae/skills`。
