# 启动与运行

## 启动

```powershell
# 生产：先构建 webdist，再由 Tauri 窗口加载 http://127.0.0.1:8866/
cd e:\BiSaiCodeProjects\LoveWorldAgent\frontend
npm install
npm run build

cd e:\BiSaiCodeProjects\LoveWorldAgent\src-tauri
cargo run
```

```powershell
# 开发：终端 1（Vite，固定 127.0.0.1:5173）
cd e:\BiSaiCodeProjects\LoveWorldAgent\frontend
npm run dev

# 开发：终端 2（Tauri 窗口加载 5173，/api 由 Vite 代理到 8866）
cd e:\BiSaiCodeProjects\LoveWorldAgent\src-tauri
cargo run -- --dev
```

- 无论开发/生产，Rust 侧都会先起 axum（默认 `127.0.0.1:8866`），窗口随后创建；`/api/health` 可用于自检。
- 开发态 Vite 固定 `127.0.0.1:5173`，`/api` 代理到 8866（含 `ws:true`）；生产态窗口同源访问 8866，`webdist` 由 axum `ServeDir` 托管并回退 `index.html`。
- 窗口标题「爱满天下」，图标 `src-tauri/static/imgs/dragon.png` → 由 `utils/icon.rs` 生成 `dragon.ico`。
- 内置浏览器需先构建 `ai_browser`，改动 C++ 后重跑 `build.ps1` 并重启应用。

## 路由概览

逐条见 `mds/路由接口文档.md`，此处只列分组：

| 前缀 | 内容 |
| --- | --- |
| `/api/health` | 健康检查（`app.rs`） |
| `/api/app` | `pick_folder`、`notify`、`runtime_info`、`log`（Tauri 原生能力） |
| `/api` | relus、skills、agents、permission、models、upload、open、`computer-use`（电脑控制开关/截图/步骤）、`word-option`/`ppt-option`/`excel-option` 与 `office-option/*`（Office 三族开关、备份、自动截图与步骤）、`mobile-option`（移动端开关、设置与步骤）、`data/clear`（清库预览/执行） |
| `/api/chat` | `/sse`、`/sse/sound/<name>`、`/stream`、`/stop`、`/approve`、`/compress`（SSE） |
| `/api/sessions` | 会话 CRUD + `/<id>/messages`、`DELETE /<id>/messages/<turn_key>`（回滚）、`/<id>/turns`、`/<id>/usage`、`/<id>/context` |
| `/api/project` | 目录、`/files`、`/file`、`/file/raw`、`/entry`、`/copy` |
| `/api/terminal` | `/ws`（主）、`/sessions`、`/open`/`persistent`/`input`/`resize`/`close`、`/stream`（兼容） |
| `/api/browser` | `start`/`rect`/`navigate`/`show`/`stop`/`state`/`tool`/`settings`/`steps`/`screenshot`/`screenshot/clear`/`import/sources`/`import/browser` |
| `/api/system` | `/theme`、`/layout` |
| `/api/agent` | `/settings` |
| `/api/mcp` | CRUD、`/status`、`/json` |
| `/api/win/update` | 标题栏主题与菜单（Tauri `set_theme`），同模块另有 `/api/app/quit` 与 `/api/app/exit` |

统一返回 `{code,msg,data}`；400 参数、404 不存在、409 冲突、429 会话超限、500 写盘失败、403 禁写。

## 构建与打包

```powershell
cd e:\BiSaiCodeProjects\LoveWorldAgent\frontend
npm run build

cd e:\BiSaiCodeProjects\LoveWorldAgent\src-tauri
cargo build --release
cargo tauri build          # 按 tauri.conf.json 出 NSIS 安装包，产物在 target/release/bundle/nsis/

# sidecar（源码/资源变更后）
powershell -ExecutionPolicy Bypass -File ai_browser\build.ps1 -SdkVersion 10.0.22621.0
powershell -ExecutionPolicy Bypass -File ai_computer_use\build.ps1
powershell -ExecutionPolicy Bypass -File ai_office_option\build.ps1
powershell -ExecutionPolicy Bypass -File ai_mobile\build.ps1
```

- `webdist` 必须保留 `base:'./'` 与 hash 路由；`vite.config.js` 的 `outDir` 为 `../webdist`，`tauri.conf.json` 的 `frontendDist` 指向同一目录。
- `bundle.resources` 打包 `../webdist`（→ `webdist`）与 `static`（→ `static`）；只读副本在 `RESOURCE_DIR/static`，可写副本在 `APP_DIR/static`；CEF sidecar 不入包，需放到 exe 同级 `browser/`。
- 打包态可写：规则/技能/智能体/配置/上传/日志在 exe 同级 `static/`；会话库 `static/data/lwa.db`；WebView2 与浏览器运行缓存统一归于 `writable_static_dir()/additional/{webview,cache}`；`computer_use`/`office_option`/`mobile` sidecar 分别从 `static/computer_use`、`static/office_option`、`static/mobile` 播种到 exe 同级目录（`computer_use` 当前只播种 exe，`models/` 与 `cuda_runtime/` 不随之复制）；桌面/Office 面板自动截图落 `static/data/{computer_screen,office_screen}`，移动端截图/录屏落 `static/data/mobile_screen`。
- 首启播种规则/技能/智能体，并由 `config::ensure_agent_files()` 生成 `agent_config.json`、`agent_permission.json`、`agent_mcp.json`。

## 配置优先级

1. `config.json`（`app/window/server/logging/ui/chat`）：可写副本（`APP_DIR/static`）→ 随包（`RESOURCE_DIR/static`）→ 内置默认值（`config.rs::DEFAULT_CONFIG`）。
2. `.loveword/*.json`：可写副本 → 随包副本 → 默认；前三个由 `ensure_agent_files()` 幂等生成。
3. 环境变量最高：`LOG_DIR`、`LOG_LEVEL`、`HTTP_HOST`、`HTTP_PORT`、`DEV_SERVER_URL`，另有 `APP_DIR`、`RESOURCE_DIR`。
4. `api_key` 明文存 `agent_config.json`（已列入文件工具禁访清单）。

## 参数

| 参数/变量 | 作用 |
| --- | --- |
| `--dev` | 窗口连接 Vite（5173） |
| `--debug` / `WEBVIEW_DEBUG=1` | 开 DevTools |
| `LOG_DIR` / `LOG_LEVEL` | 日志目录 / 级别 |
| `HTTP_HOST` / `HTTP_PORT` | HTTP 监听（默认 127.0.0.1:8866） |
| `DEV_SERVER_URL` | 开发态窗口地址（默认 http://127.0.0.1:5173） |
| `APP_DIR` / `RESOURCE_DIR` | 冻结态可写目录 / 资源目录 |

## 验证要点

1. 窗口标题「爱满天下」，默认 1600×1000（min 1080×778）；三栏；右栏默认收起，展开后 420~1000。
2. 顶栏选项目目录（Tauri 目录对话框）后文件/命令/终端生效；未选时发送置灰、后端 SSE 报「请先选择项目文件夹」。
3. 右栏四入口：待办 / 浏览器 / 文件 / 终端；切 tab 不销毁终端会话。
4. 会话：新建为草稿，首条消息才创建；重启后列表与消息仍在；状态回写含 `failed`；`messages.data` 为 goose `Message` JSON；旧结构库启动时备份为 `lwa.db.bak`。
5. 历史回放按 goose `Message.content[]` 还原；消息区 thinking 默认折叠，工具卡按输出顺序平铺；直接 `browser_*`/`computer_*`/`word_*`/`ppt_*`/`excel_*`/`mobile_*` 统一渲染单卡（`BuildToolCall`），子智能体消息按 callId 归入 SubAgents 卡，未知工具落 `UnsupportedCard`。
6. 工具卡：命令/终端→CommandCall、`mcp_`→McpCall、`rule_`→RuleCall、`skill_`→SkillCall、`file_`→FileEdit、`browser_*`/`computer_*`/`word_*`/`ppt_*`/`excel_*`/`mobile_*`→BuildToolCall、`agent_call`→SubAgents、手动压缩→CompactionCard，其余→`UnsupportedCard`（含右对齐黄色「继续」按钮）；`ask_user`/`terminal_open` 不单独出卡。
7. 审批：`actionRequired(toolConfirmation)` 弹确认条；允许后 `approve` + `stream{resume}` 续流；拒绝后卡上标「未获批准，未执行」；无待决时 `/approve` 返回 409。
8. 设置九项：规则/技能/对话/模型/系统/权限/智能体/内置工具/MCP；智能体页含运行参数；「内置工具」为浏览器/电脑/Word/PPT/Excel/移动端六标签（默认浏览器），浏览器页含启用、自动截图、Cookie 导入与清截图（缓存路径已收拢），电脑页含启用与自动截图，三页 Office 分别读写 `/api/word-option|ppt-option|excel-option`（启用、独立自动截图、共享备份保留数，已移除 `allowDirs`），移动端页读写 `/api/mobile-option`（启用、adb 路径、默认设备、截图最大边）。
9. 浏览器：点「打开浏览器窗口」→ 出现 → 点 ✕ 只隐藏 → 再点 2s 内复现；智能体点击/悬停/输入时可见模拟鼠标与涟漪；应用启动阶段由 `InitState.vue` 遮罩避开首屏白屏。
10. 上下文：`POST /api/chat/compress` 走 SSE 手动压缩并输出 `CompactionCard`（含 409 并发锁定）；`GET /api/sessions/<id>/usage` 读累计，待办面板按当前选中模型上下文计算占用百分比进度条；占用超 80% 自动压缩；撤回轮次走 `DELETE /api/sessions/<id>/messages/<turn_key>?after=1` 确保刷新后一致。
11. 打包态：`resources/webdist` 与 `resources/static` 存在；首启生成 `static/data/lwa.db`、可写 `.loveword/`；缓存与 WebView2 归入 `static/additional/{webview,cache,browser_cache}`；`browser/` 内有 sidecar 与 CEF 文件。
12. 回归脚本在 `.trae/skills/project-test/scripts/`（`.codeartsdoer/skills` 保留同名副本）；分析产物在 `test/temp/`。
13. 设置-内置工具-电脑开关经 `PUT /api/computer-use` 落 `computer` 组与 `agent_computer_use.json`（含自动截图）；关闭时结束 sidecar、锁定 `computer-control` 技能并停用 `computeruse-agent`；菜单「工具 → 清除数据」弹出预览，运行或压缩中确认按钮显示「请先停止任务」。
