## 前端约定

- 纯 JavaScript（`.js` / `<script setup>`），不引入 TypeScript；4 空格缩进，无分号/单引号。
- UI 统一用 `components/shadcn_ui` 的 shadcn-vue 组件 + Tailwind 原子类；不再依赖 Element Plus，也不使用 `size="small/default"` 一类属性。
- 主题 `dark/light/system` 由 `theme.js` 切换 `html.dark`，持久化 `config.json.ui.theme`。
- Chat 三栏：左 200~420（默认 264）、右 420~1000（默认收起，无存储值按 `(innerWidth-24)×44%`，保证中栏 ≥480）；窗口 1600×1000，min 1080×778。
- 右栏开关用 `v-if="rightOpen"`（面板与分割线同时消失）；展开/收起与 resize 用 `:key` 重建分栏，输入草稿双向同步防丢。
- 文件面板：预览在左、树在右（默认 23%，拖拽 20%~70%）；目录懒加载；右键 6 项菜单；`Ctrl+S` 保存；无工具栏与「最近」。
- 设置页统一卡片容器、14px/600 分组标题、主题色开关（shadcn-vue Switch/Tabs）。
- 工具失败态以 `part.status` / `isError` / `meta.ok` 为准；`goosePart.js` 把 goose `Message.content[]` 转成 parts，前端只面向新契约。
- 卡片职责单一：工具卡平铺，不再聚合 `ToolGroup`，也不在报错时折叠前置内容；直接 `browser_*`/`computer_*`/`word_*`/`ppt_*`/`excel_*`/`mobile_*` 统一由 BuildToolCall 渲染内置工具单卡，子智能体执行统一由 SubAgents 卡渲染，手动压缩流式输出 CompactionCard，未知/暂不支持工具走 UnsupportedCard（右侧黄色「继续」按钮）。
- 对话事件：SSE 直出 goose `AgentEvent`（`message`/`usage`/`messageUsage`/`mcpNotification`/`historyReplaced`）；`chatEventReducer.js` 按消息 id 合并分片，`chatContract.js` 定义 `AGENT_EVENT_TYPES` 与 `BLOCK_TYPES`，`chatHelpers.js`/`inputHelpers.js`/`codeLang.js` 承担状态、消息格式与代码语言辅助。
- 会话落库由后端状态机驱动：user 消息随 `/stream` 写入、assistant 随效果落库；前端只在加载时按 `after_seq` 回放，不再 POST 消息。
- 标题栏与菜单由 `theme.js → POST /api/win/update` 驱动，Rust 侧调用 `window.set_theme` 并记录重绘策略。

## 已清理能力

Python 运行时与 `main.py`、`config.py`、`pyproject.toml`、`.venv`、`build/`、`dist/` 已删除；`pywebview`、`Sanic`、`openai-agents`、`pywinpty`、`pythonnet`、`PyInstaller`、Element Plus 均不再是现行依赖。A2A、长期记忆、追踪、专家编排、示例用户接口与前端测试体系未引入；MCP 保留（`agent/mcp.rs` + `.loveword/agent_mcp.json`）。

| ai_office_option | Rust 2021（MSRV 1.88）/ windows 0.62 / serde_json / chrono | 单 bin `office_option`；32 个 `word_*/ppt_*/excel_*`；COM IDispatch 晚绑定；Word/PPT/Excel 各独立 STA；三族共用 `loveworld_office_option` 管道与 `.loveword/agent_office.json`（含分族 `auto_screenshot`，已移除 `allowDirs`）；日志 `static/logs/office_option.log` |

| frontend | Vue 3 / Vite 6 / shadcn-vue + reka-ui + Tailwind / Monaco / @xterm/xterm | `outDir ../webdist`、`base './'`、dev 5173 代理 `/api`；fetch + SSE（AbortController）；无 pinia，状态就近持有 |

运行前置：

- ai_browser：Windows SDK 10.0.22621、CEF 发行包解压到 `third_party/cef/`、Qt `msvc2019_64`。
- ai_computer_use：Windows x64、Rust 1.88+；UIA 需 COM MTA，操作管理员窗口受 UIPI 限制；`omni` 需 `omni_parser/models/{ocr,ms_vision}`、`omni_parser/cuda_runtime` 与 NVIDIA CUDA 12.9 驱动。
- frontend：Node 18+；构建后 `webdist` 由主应用托管。
