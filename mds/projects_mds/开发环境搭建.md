## 初始化

```powershell
cd e:\BiSaiCodeProjects\LoveWorldAgent\frontend
npm install
npm run build

cd e:\BiSaiCodeProjects\LoveWorldAgent\src-tauri
cargo build

cd e:\BiSaiCodeProjects\LoveWorldAgent\ai_mobile
cargo build

cd e:\BiSaiCodeProjects\LoveWorldAgent\ai_office_option
cargo build --release

cd e:\BiSaiCodeProjects\LoveWorldAgent\ai_computer_use
cargo build --release
```

- 首次 `cargo build` 需编译 tauri/axum/rusqlite/goose 全量依赖，耗时较长（10 分钟以上属正常），务必等其成功后再 `cargo run`。
- goose 四件套锁定 `=0.1.0-alpha.13`，`goose-providers` 启用 `native-tls`（Windows Schannel），不需要 OpenSSL 或 aws-lc-rs；升级时四处版本必须同步。
- `webdist` 是窗口内容来源（axum 静态服务 + Tauri resource），缺它窗口会空白或 404。
- 前端已含 `@xterm/xterm`、`@xterm/addon-fit`、`reka-ui`、`lucide-vue-next`。
- ai_computer_use 的 `omni` 依赖 CUDA 12.9 + cuDNN 9.24 + ORT 1.30；DLL 在 `ai_computer_use/omni_parser/cuda_runtime`，构建后用 `build.ps1` 随包到 `src-tauri/static/computer_use/cuda_runtime`。
- `src-tauri` 的 `tauri` 已启用 `devtools` feature，开发态与打包态都可从菜单「工具 → 开发者工具」打开 WebView2 DevTools。

## 内置浏览器（CEF）

1. VS Installer 勾选 Windows 11 SDK 10.0.22621.0、MSVC v142、C++ CMake tools（含 Ninja）。
2. 下载 CEF 111.2.7 Standard windows64，解压到 `ai_browser/third_party/cef/`。
3. 构建与调试：

```powershell
powershell -ExecutionPolicy Bypass -File ai_browser\build.ps1 -SdkVersion 10.0.22621.0
powershell -ExecutionPolicy Bypass -File ai_browser\test_run.ps1 -Url https://example.com
Stop-Process -Name browser_panel
```

- 产物 `ai_browser/out/Release/`：`browser_panel.exe`、`libcef.dll`、pak/locales 等；开发态 `utils/browser.rs` 直接取该路径。
- 打包态从 exe 同级 `browser/` 取 sidecar；`tauri.conf.json` 的 resources 只含 `webdist` 与 `static`，CEF 目录需手工放置。
- 改动 `ai_browser/src/**` 后必须重跑 `build.ps1` 并重启应用（sidecar 不热更新）。
- 构建坑见 `注意事项.md`「CEF 构建坑」。

## 目录与环境变量

- 约定不入库：`node_modules/`、`webdist/`、`src-tauri/target/`、`ai_browser/{third_party,build,out}/`、`ai_computer_use/target/`、`ai_office_option/target/`、`ai_mobile/target/`、`src-tauri/static/{logs,uploads,additional}/`、`test/scripts/`、`test/temp/`。
- `src-tauri/static/.loveword/` 需随仓库分发；`src-tauri/static/data/lwa.db` 为运行期数据（旧结构库首次启动自动备份为 `lwa.db.bak`）。
- `test/temp` 放临时产物、验收日志/截图与题目下载暂存；`test/scripts` 放临时脚本，收尾清理。
- 分析/验收技能在 `.trae/skills/{project-init-analyze,project-test,measuring-repairing}`（`.codeartsdoer/skills` 保留同名副本）；随包业务技能为 `browser-automation`、`computer-control`、`word-control`、`ppt-control`、`excel-control`、`mobile-control`。
- 移动端前置：adb 可在 PATH / `ANDROID_HOME` / 设置 `adbPath` 中解析；真机需开启 USB 调试并授权，模拟器可直接被 `adb devices` 识别。
- 日志 `src-tauri/static/logs/app.log`；会话库 `src-tauri/static/data/lwa.db`；WebView2 与浏览器缓存统一到 `src-tauri/static/additional/{webview,cache}`（`browser_panel` 经 `--cache`/`--root-cache` 指向 `additional/cache`，已忽略）。
- 可覆盖环境变量：`LOG_DIR`、`LOG_LEVEL`、`HTTP_HOST`、`HTTP_PORT`、`DEV_SERVER_URL`、`WEBVIEW_DEBUG=1`、`APP_DIR`、`RESOURCE_DIR`。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| `cargo build` 长时间无输出 | 首次编译依赖；看 `target/` 增长，勿中途 kill |
| `link.exe not found` / `msvc` 链接失败 | 装 VS Build Tools（C++ 桌面开发）+ Windows SDK |
| 窗口白屏 / `webdist` 404 | 先 `cd frontend && npm run build` |
| 启动后提示端口绑定失败 | 8866 被占用：`netstat -ano \| findstr :8866` 结束进程，或设 `HTTP_PORT` |
| WebView2 报错 / 页面空白 | 安装 WebView2 Runtime（Edge 已带则修复安装） |
| 5173 被占用 | 关闭占用进程或改 Vite 端口（同时改 `server.dev_server_url`） |
| npm 阻止脚本 | `npm rebuild esbuild` 或批准脚本 |
| 页面样式异常 | 在 `frontend` 重跑 `npm install && npm run build` |
| 右栏浏览器报 sidecar 不存在 | 跑 `build.ps1`，确认 `ai_browser/out/Release/browser_panel.exe` |
| `build.ps1` 字符串未终止 | `.ps1` 存 UTF-8 with BOM |
| SDK 找不到 | 安装 10.0.22621.0 或传 `-SdkVersion` |
| goose 编译报 TLS/链接错误 | 确认 `goose-providers` 保留 `native-tls`，四处 goose 版本一致（`=0.1.0-alpha.13`） |
| 点「打开浏览器窗口」报 503 | 看 `app.log` 的 `异步启动失败` 与 `/state.error` |
| 关闭浏览器后再也打不开 | 重编 sidecar；✕ 只隐藏保活 |
| NSIS 打包报文件占用 | 先停 sidecar，清理 `src-tauri/static/{additional,logs,uploads}` 运行缓存 |
| 移动端工具报 `ADB_NOT_FOUND` | 在设置 → 内置工具 → 移动端填写 adb 路径，或把 platform-tools 放到 `src-tauri/static/mobile/platform-tools/` |
| 移动端报 `DEVICE_REQUIRED` | `adb devices` 有多台在线设备，填写默认设备序列号 |
| 移动端报 `UNSUPPORTED_INPUT` | 设备不支持剪贴板广播；改用英文/数字输入或安装 ADB Keyboard |
