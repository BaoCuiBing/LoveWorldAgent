# 项目概述

LoveWorldAgent（窗口标题「爱满天下」）是 Windows 桌面端 AI 编程智能体：Tauri v2 + Rust 开窗，Vue 3 + Tailwind v4 + shadcn-vue 渲染，Rust 侧 axum 提供本机 HTTP（`127.0.0.1:8866`）。主智能体在所选项目目录内读写文件、执行命令、维护规则、按需读取技能、调度子智能体并驱动内置 CEF 浏览器；前端只经 `/api/*` 取数，会话存 SQLite，重启可回放。

## 定位与边界

- 单窗口宿主，前端不直接读写文件；内置浏览器是 CEF sidecar 自建的独立顶层窗口。
- 项目目录经顶栏选择（`POST /api/app/pick_folder` 走 Tauri 原生目录对话框，或 `PUT /api/project`），写入 `config.json.app.project_path`；文件/命令工具、终端 cwd、文件树均以此为根，未选时统一提示「请先选择项目文件夹」。
- 主智能体不联网检索，网页访问走浏览器工具；白名单外命令需审批；文件工具不跳出项目目录。
- 无长期记忆与多智能体编排；规则是业务事实源，技能只读注入。MCP 服务经 `.loveword/agent_mcp.json` 配置，启动后由 `mcp::spawn_startup_connect()` 后台常驻连接已启用服务，并纳入 `mcp` 权限组。

## 当前能力

1. **窗口壳**：`src-tauri/src/main.rs` → `lib.rs`，支持 `--dev/--debug`（或 `WEBVIEW_DEBUG=1`）；生产窗口加载 `http://127.0.0.1:8866/`（axum 托管 `webdist`），开发连 Vite（5173），首屏加载期间由 `InitState.vue` 轮询健康检查遮罩防白屏。窗口 1600×1000、min 1080×778；Tauri 原生菜单（`utils/menu.rs`）+ `window.set_theme` 标题栏（`utils/titlebar.rs`），关闭前由 `/api/app/quit` 限时清理后台进程。
2. **HTTP**：`app.rs` 在 `http-server` 线程内建 tokio 多线程运行时，axum 合并 `api.rs` 与 `rouer/*` 路由（含 `/api/computer-use/*`、`/api/{word,ppt,excel}-option`、`/api/office-option/*`、`/api/mobile-option/*`、`/api/data/clear`），Fallback 静态服务（SPA 回退 `index.html`）+ `/api/health`；CORS 全放行；`AppState::active_tasks` + `SessionTaskGuard` 拦截并发流与压缩（409）。
3. **规则**：`.loveword/relus/*.md`，frontmatter `alwaysApply`/`description`；仅始终生效项注入，其余按 description 建按需索引。
4. **技能**：`.loveword/skills/<name>/SKILL.md`，CRUD/启停/搜索；随包 `browser-automation`、`computer-control`、`word-control`、`ppt-control`、`excel-control`、`mobile-control` 六个锁定技能，启停随「内置工具」对应开关同步，手工修改被拒。
5. **对话页**：三栏拖拽分栏——左会话（200~420，默认 264）、中对话、右栏（420~1000，默认收起，无存储值时按 `(innerWidth-24)×44%`，保证中栏 ≥480）。输入区三 chip + `+` 菜单；`#`/`/` 走 `InsertContext.vue`，`#File:`/`#Folder:` 走路径 popover，`@` 弹智能体；模型切换/调参联动待办面板上下文上限，支持基于消息粒度的撤回回滚（`DELETE /api/sessions/<id>/messages/<turn_key>?after=1`）。
6. **会话持久化**：SQLite `src-tauri/static/data/lwa.db`，`store_sqls/db.rs` 建 `sessions`、`messages`（`data` 列存 goose `Message` JSON，`UNIQUE(session_id,seq)`）、`turns`、`session_usage`、`session_context`、`context_facts`；旧结构库首次启动备份为 `lwa.db.bak` 后重建；状态 `running/completed/interrupted/failed`；新建会话仅草稿，首条消息由后端创建并落库，assistant 与压缩结果消息均随流程落库。
7. **消息渲染**：后端直出 goose `Message`，前端按 `content[]` 块渲染 text/thinking/toolRequest/toolResponse/actionRequired/CompactionCard（`goosePart.js` 转 parts）。thinking 默认折叠；text 用 `MdShow`（markdown-it + highlight.js + mermaid）；工具按前缀路由 McpCall/RuleCall/SkillCall/FileEdit/CommandCall/BuildToolCall（统一覆盖 `browser_*`/`computer_*`/`word_*`/`ppt_*`/`excel_*`/`mobile_*`），子智能体走 SubAgents，手动压缩走 CompactionCard，未知或暂不支持工具走 `UnsupportedCard`（右侧黄色「继续」按钮右对齐）；审批为 `actionRequired.toolConfirmation` 确认条，提问卡就地作答；工具卡平铺；`todos` 由 `UpdateList` 渲染。
8. **右栏四面板**：待办 / 内置工具 / 文件 / 终端（`RightTools.vue`，`v-show` 保活）。
   - 待办与上下文：`AgencyList` 两折叠区；上下文按当前选中模型上下文计算 `session_usage.total / limit` 进度条与「规则/技能/文件/其他」标签页；点「压缩」走 `/api/chat/compress` SSE 流式压缩并输出压缩卡。
   - 内置工具：`BuildPanel` 复用 `SidecarPanelBase` 手风琴聚合 `BroweringPanel` / `ComputerUsePanel` / `OfficeOptionPanel` / `MobilePanel` 步骤流与自动截图缩略（点击仅预览，截图绝不进 LLM）。
   - 文件：`FileCode` 左预览（`CodeEditor` / `OfficeView`）右文件树（默认 23%，20%~70%），目录懒加载、右键菜单、`Ctrl+S` 保存。
   - 终端：xterm 多标签，一标签一条 `/api/terminal/ws`，用户池 12 / 智能体池 4，断线退避重连。
9. **设置弹窗**：760px 九项（规则/技能/对话/模型/系统/权限/智能体/内置工具/MCP）；`openState {tab,addModel,permissionMode}` 深链；权限页三模式 + 8 组手风琴 + custom 白名单；智能体页含运行参数（`GET/PUT /api/agent/settings`）；「内置工具」为浏览器/电脑/Word/PPT/Excel/移动端六标签（默认浏览器），浏览器含启用/自动截图/Cookie 导入/清截图，电脑含启用与自动截图（`agent_computer_use.json`），三页 Office 复用 `OfficeOptionEditBase`（启用/独立自动截图/共享备份保留数，已移除 `allowDirs`），移动端页联动 `/api/mobile-option`。
10. **项目目录接口**：`/api/project` 当前目录、`/files` 单层懒加载、`/file` 文本读写、`/file/raw` 二进制、`/entry` 创建/删除、`/copy` 复制；禁写清单 403。
11. **权限与审批**：`agent_permission.json` 每次读盘；`auto` 下未列 PowerShell 命令默认放行，仅灰条目或输出重定向中断；浏览器 21 项按 browser 组判定；电脑控制 23 个 `computer_*` 按 computer 组判定（组关闭时硬拦截并同步技能/子智能体/sidecar）；Word 12 个、PPT 10 个、Excel 10 个按各自组判定并同步控制技能、use-agent 与 sidecar 族开关；移动端 28 个 `mobile_*` 按 mobile 组判定并同步技能、子智能体与 sidecar。审批由 goose 状态机的 `Approval` 步骤产出 `actionRequired`，`POST /api/chat/approve` 写 `toolConfirmationResponse`，再 `POST /api/chat/stream {resume:会话id}` 续流。
12. **模型**：`.loveword/agent_config.json` 的 `llm` 数组（provider/base_url/api_key/model/enabled/context/thinking）；`agent/models.rs` 与 `model_support/huawei_maas.rs` 适配 deepseek/kimi/qwen/openpangu/glm（含华为云 MaaS V2 归一化），经 `goose-providers` 接入，`vision` 由服务商注册表推导。
13. **智能体**：goose 状态机 `Approval → PromptParts → ToolOperation → UnhandledToolCalls → MaxTurns → InferenceRunner → ExitOnError`；内建工具进程内适配 goose `ToolProvider`，外部 MCP 走 MCP 客户端；`agent/agents_repo.rs` 管 `.loveword/agents/<id>/AGENT.md` 与 `GLOBAL_PROMPT` + `PROVIDER_PATCHES`；主智能体全量工具，子智能体按 tools 子集（`rule/skill/file/command/browser/computer/word/ppt/excel/mobile`）；随包 6 类智能体骨架；用量经 `usage`/`messageUsage` 事件下发。
14. **内置浏览器**：Qt6 外壳（Bcb 控件 + QSS）+ CEF 111.2.7；21 个主应用 `browser_*` 工具（sidecar 内含 `browser_*`/`ui_*`/`window_*`）；模拟鼠标覆盖层（箭头 + 点击涟漪）；`utils/browser.rs` 负责启停、管道 v2 与截图（缓存收拢至 `static/additional/cache`）。
14b. **Office 工具**：`ai_office_option/` 独立 Rust sidecar（COM IDispatch 晚绑定 + 每族独立 STA 队列 + Win32 可见窗口自动截图），32 个 `word_*/ppt_*/excel_*` 以完整本机路径定位文档（仅拒 UNC/设备路径与 `..` 穿越，允许全本机路径），共用命名管道 `loveworld_office_option`；`utils/office_option.rs` 与 `sidecar_pipe.rs` 负责托管/播种/分族开关/自动截图剥离；随包 `static/office_option/office_option.exe`。
14c. **移动端工具**：`ai_mobile/` 独立 Rust sidecar（adb），28 个 `mobile_*` 覆盖设备/应用/屏幕/元素树/输入/日志/录屏/批量；`utils/mobile.rs` 托管命名管道 `loveworld_mobile`；`GET/PUT /api/mobile-option` 落 `.loveword/agent_mobile.json`。
15. **主题与打包**：深浅随主题 → `set_theme` + 原生菜单；`tauri.conf.json` 指定 `frontendDist=../webdist`、`bundle.targets=["nsis"]`、resources 为 `../webdist` 与 `static`；CEF sidecar 打包态取 exe 同级 `browser/`；computer/office/mobile sidecar 分别从 `static/computer_use`、`static/office_option`、`static/mobile` 播种；WebView2 与浏览器缓存收拢至 `static/additional/{webview,cache,browser_cache}`。

## 架构

```text
Tauri v2 窗口（生产 http://127.0.0.1:8866 / 开发 127.0.0.1:5173）
  └─ Vue 3 + Tailwind v4 + shadcn-vue（reka-ui）
       ├─ Chat.vue（三栏 + 会话 + 消息 + 输入）
       ├─ RightTools.vue（待办 / 浏览器 / 文件 / 终端）
       ├─ SetingDialog.vue（九项，openState 深链）
       ├─ others/ClearData.vue（菜单「工具 → 清除数据」预览/确认）
       └─ request_data.js → /api/*
axum + tokio（127.0.0.1:8866，http-server 线程）
  ├─ api.rs：/api/app/*（Tauri 原生能力：目录选择、通知、运行环境、前端日志）
  ├─ rouer/*：relus/skill/agent/chat/session/system/model/permission/project/terminal/browser/computer-use/office-option（word/ppt/excel 三路由）/mobile-option/mcp/upload/other
  ├─ agent/agent_core/state_machine.rs：goose 状态机装配 + AgentEvent 直出
  ├─ agent/agent_core/{goose_session,goose_tools,goose_approval}.rs：会话落库 / ToolProvider / 审批门
  ├─ agent/store_sqls → rusqlite src-tauri/static/data/lwa.db（messages.data 存 goose Message JSON）
  ├─ agent/permission → .loveword/agent_permission.json
  └─ utils/browser.rs（启动锁 + 异步受理 + 管道 v2）→ CEF 独立顶层窗口 sidecar
```

## 数据流

```text
项目目录 → /api/app/pick_folder（Tauri 目录对话框）或 PUT /api/project → config.json app.project_path → 工具根 / 系统提示 / 终端 / 文件树
会话 → /api/sessions → store_sqls（SQLite，messages.data 为 goose Message JSON）→ 列表 / 回放
对话 → POST /api/chat/stream → agent/state_machine（goose 状态机）→ SSE AgentEvent：message/usage/messageUsage/mcpNotification/historyReplaced
审批 → goose Approval 产出 actionRequired → permission 读权限文件 → approve 写 toolConfirmationResponse → stream{resume}；always 写 custom
终端 → /api/terminal/ws（一标签一条）→ portable-pty(cmd.exe) → data/exit，上行 input/resize
浏览器 → /api/browser/start（异步）→ /state 轮询 → utils/browser.rs → CEF 顶层窗口；browser_click/hover/type 回传坐标 → CursorOverlay
模型 → /api/models → agent_config.json llm
主题 → /api/system/theme；/api/win/update → window.set_theme + 菜单
菜单「工具」→ 开发者工具（open_devtools）/ 清除数据（`lwa:clear-data` → ClearData.vue → GET/POST /api/data/clear）
```

## 子项目概览

LoveWorldAgent 由主应用与四个独立 sidecar、一个前端子项目组成；五者共同构成完整产品，子项目不参与 `src-tauri` 的 Cargo 构建。

### ai_browser（内置浏览器 sidecar）

- 定位：C++17 + Qt6 + CEF 111 独立进程 `browser_panel.exe`，主应用按需拉起并通过命名管道 `loveworld_browser_panel` 驱动。
- 边界：只负责渲染网页、DOM 级交互、控制台/网络采集；不做推理、不落库、不直接读写主应用配置。
- 能力：主应用绑定 21 个 `browser_*` 工具（sidecar 内含 `browser_*`、`ui_*`、`window_*`）；事件回传 `title/address/tabs/dialog/ui`；日志 `static/logs/browser_panel.log`。

### ai_computer_use（桌面自动化 sidecar）

- 定位：Rust 独立 crate `computer_use`（内置工具，非外置 MCP），入口 `pipe --pipe=<name>` 与 `omni serve/parse`；主应用通过 `loveworld_computer_use` 管道托管。
- 能力：23 个 `computer_*` 工具（键鼠点击/双击/右键/拖拽、输入与热键/按键/滚轮、UI 属性设置、窗口与进程管理、UI 自动化树/桌面状态/分辨率/光标位置等）；`omni serve` 用 CUDA ONNX 会话做图标检测（icon_detect v2/v3）、OCR（PP-OCRv4）与标注图输出；支持操作后自动截图落 `static/data/computer_screen` 供面板展示。
- 边界：不做任务编排；受 UIPI 限制，操作管理员窗口需提权；日志 `static/logs/computer_use.log`。

### ai_office_option（Office 自动化 sidecar）

- 定位：Rust 独立 crate `office_option`（COM IDispatch 晚绑定），仅 `pipe --pipe=<name>` 单模式；主应用通过 `loveworld_office_option` 管道托管。
- 能力：32 个工具——12 个 `word_*`、10 个 `ppt_*`、10 个 `excel_*`；Word/PPT/Excel 各独立 STA 线程互不阻塞；支持 `auto_screenshot.{word,ppt,excel}` Win32 可见窗口自动截图至 `static/data/office_screen` 供右栏面板展示。
- 边界：已移除目录白名单（`agent_office.json` 无 `allowDirs`），允许全本机合法路径（仅拒绝 UNC/设备路径与 `..` 穿越）；保存前 `.bak` 轮转；日志 `static/logs/office_option.log`。

### ai_mobile（Android 移动端 sidecar）

- 定位：Rust 独立 crate `mobile_use`，通过 adb 操作真机/模拟器；主应用经命名管道 `loveworld_mobile` 托管。
- 能力：28 个 `mobile_*` 工具——设备与应用列表、前台应用、启动/停止/安装/卸载、屏幕尺寸、截图、uiautomator 元素树（`@eN` + bounds）、点击/双击/长按/滑动（坐标自动缩放）、按键与网址、文本输入、方向与模拟位置、剪贴板、logcat/崩溃、录屏、批量命令。
- 边界：不做云端设备与 iOS；非 ASCII 输入依赖设备剪贴板能力；配置落 `.loveword/agent_mobile.json`，截图/录屏落 `static/data/mobile_screen`，日志 `static/logs/mobile_use.log`。

### frontend（WebView2 前端）

- 定位：Vue 3 + Vite + shadcn-vue + Tailwind，构建产物 `webdist`，开发态由 Vite 5173 加载、打包态由 axum 8866 托管。
- 页面：hash 路由仅 Chat（三栏）；九项设置弹窗；全部能力经 `/api/*`。
- 关键约定：`Chat.vue` 是会话/右栏/流式状态唯一来源；卡片渲染统一 `md_show`；接口集中在 `api/request_data.js`。
